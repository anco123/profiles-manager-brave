Chọn profile để ghi. Trong cửa sổ trình duyệt của profile sẽ hiện nút ⏺ REC ở góc dưới phải -- bấm nút đó để bắt đầu ghi, bấm lại để tạm dừng / ghi tiếp (nhiều lần ghi nối thành 1 đoạn); bấm ⏹ Xuất cạnh đó thì code cả đoạn tự chèn vào chỗ con trỏ ở đây (kèm copy clipboard). Giữ Alt + rê chuột để xem các lớp phần tử chồng nhau dưới con trỏ (lăn chuột đổi lớp, nhả Alt để chọn selector + hành động). Nút ☰ cạnh REC: xem / sửa các bước (cha-con, selector, hành động). Chèn code ở thanh trên cùng = chèn tất cả các bước.
