Fingerprint

On by default: generates a random, internally-consistent identity (GPU string, CPU/RAM, canvas & audio noise, font list) on top of the User-Agent/viewport/locale/timezone above, and turns on WebRTC leak protection for this profile. Uncheck only if you deliberately want this profile to report this machine's real hardware (e.g. every profile without it enabled reports the SAME real GPU/CPU/RAM/canvas/audio, since there's nothing profile-specific being spoofed). Fingerprint

On by default. Each profile in this batch gets its own, distinct generated identity — not one fingerprint shared by all of them (that would defeat the point). This also varies each profile's viewport size a little, snapped to realistic values close to what you set below (maximized-window or Windows-Snap-half widths, not an arbitrary pixel count) — so a batch of "independent" profiles doesn't all report the exact same window size either. Locale/timezone/engine are still shared across the batch, same as always. Uncheck only if you deliberately want this batch to report this machine's real, shared hardware instead.

Import profiles

A JSON array, one object per profile. Any field buildProfileObject() understands is accepted — name, userAgent, viewportWidth/viewportHeight, locale, timezoneId, proxyServer/proxyUsername/proxyPassword, and an optional fingerprint object (any subset of platform, hardwareConcurrency, deviceMemory, webglVendor, webglRenderer, fonts). Missing name → auto-named "Imported N". Missing/omitted fingerprint → one is generated for you, so every imported profile still ends up distinct.

Extensions

Every profile loads these PLUS whatever it has in its own "Extension folders" field (set when creating/editing that profile) — same folder on disk for every window, so there's no extra disk usage, though each open Chrome window still runs its own copy of the extension in its own memory (separate processes can't share that part).

Takes effect on a profile's next launch — already-open windows need to be closed and reopened, but the server itself does not need restarting (unlike Settings).

Proxy list

Có danh sách → mỗi profile chạy bằng Run được gán tạm proxy ít profile dùng nhất, tối đa "Max per proxy" profile/proxy (bỏ qua proxy riêng, không sửa profile). Để trống rồi Save = mỗi profile dùng proxy riêng như cũ (set tay).

Đang chạy vẫn Save được: profile mở sau đó dùng danh sách mới, profile đang chạy giữ proxy cũ tới khi xong.
