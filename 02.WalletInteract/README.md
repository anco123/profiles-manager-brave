# ZEC + EVM Wallet Generator

Node.js project that generates BIP-39 mnemonics and derives:

- Zcash transparent Mainnet address (`t1...`)
- Zcash transparent private key
- EVM address
- EVM private key

## Install

```bash
npm install
```

## Run

```bash
npm start
```

The program asks:

```text
Mnemonic 12 hay 24 words? [24]:
So luong vi muon tao? [1]:
```

## Important Zcash note

The project deliberately supports both 12 and 24 BIP-39 words because the application requested both.

For NEW Zcash wallet generation, Zcash ZIP 32 guidance requires at least 256 bits of entropy, which corresponds to a 24-word BIP-39 mnemonic. Therefore 24 words should be used for a Zcash wallet intended to follow that requirement.

The ZEC address generated by this project is a transparent P2PKH `t1...` address using:

```text
m/44'/133'/0'/0/index
```

This project does NOT implement Sapling or Orchard shielded addresses.

## EVM derivation

The EVM address uses:

```text
m/44'/60'/0'/0/index
```

Therefore the same mnemonic can deterministically produce an EVM address alongside the ZEC transparent address.

## Security

This tool generates real wallet secrets locally.

- Do not send mnemonic/private keys to a server.
- Do not put generated output into Git.
- Do not use example/test output with real funds.
- For meaningful funds, consider an audited wallet implementation/hardware wallet.
